# Python 自学仓库

系统自学 Python 的练习仓库。每个板块 = 可运行代码 + 一份统一笔记。

环境：Python 3.12.4 + tkinter 8.6

## 目录约定

| 目录 | 用途 |
|---|---|
| `src/` | 代码，一板块一子目录 |
| `notes/` | 教学笔记，一板块一个 md |
| `docs/` | 外部待阅资料 |

代码按课编号 `01_xxx.py`，与笔记章节一一对应。逐行细节写注释，体系讲解写笔记，两边不重复维护。
