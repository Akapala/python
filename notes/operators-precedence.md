## 一、速查表（优先级从高到低）

| 优先级 | 运算符 | 类别 | 一句话说明 |
|--------|--------|------|-----------|
| 1 | `()` `[]` `{}` `{**}` | 绑定/容器 | 元组、列表、字典/集合/解包构造 |
| 2 | `obj.attr` `obj[i]` `obj[i:j]` `f(...)` `obj[...]` | 读取 | 属性、切片、调用、subscript |
| 3 | `await x` | await | 协程等待表达式 |
| 4 | `**` | 算术 | 乘方（指数） |
| 5 | `+x` `-x` `~x` | 一元 | 正号 / 负号 / 按位取反 |
| 6 | `*` `@` `/` `//` `%` | 算术 | 乘 / 矩阵乘（numpy 用）/ 除 / 整除 / 模 |
| 7 | `+` `-` | 算术 | 加、减 |
| 8 | `<<` `>>` | 位运算 | 左移 / 右移 |
| 9 | `&` | 位运算 | 按位与 |
| 10 | `^` | 位运算 | 按位异或 |
| 11 | `|` | 位运算 | 按位或 |
| 12 | `<` `<=` `>` `>=` `==` `!=` `in` `not in` `is` `is not` | 比较 / 成员 / 身份 | 可链式（如 `1 < x < 10`） |
| 13 | `not x` | 逻辑 | 逻辑非 |
| 14 | `and` | 逻辑 | 逻辑与（短路） |
| 15 | `or` | 逻辑 | 逻辑或（短路） |
| 16 | `x if cond else y` | 条件表达式 | 三元条件 |
| 17 | `:=` | 海象（Python 3.8+） | 赋值表达式，可在表达式中赋值 |
| 18 | `lambda` | lambda | 匿名函数定义，最低优先级 |

## 二、分类详解 + 示例

### 1. 算术运算符

```python
+ - * / // % **
```

- `+ - * /`：常规加减乘除
- `//`：**向下取整**整除，`-7 // 2 == -4`（不是 -3）
- `%`：取模，结果符号与除数一致
- `**`：乘方，`2 ** 10 == 1024`

```python
>>> 10 / 3
3.3333333333333335
>>> 10 // 3
3
>>> -7 // 2
-4
>>> 10 % 3
1
>>> 2 ** 10
1024
```

### 2. 比较运算符

```python
==  !=  <  >  <=  >=
```

返回 `bool`。**Python 的比较可链式**（C/C++ 不行）：

```python
1 < x < 10         # 等价于 1 < x and x < 10
a == b == c        # 等价于 a == b and b == c
```

### 3. 逻辑运算符

```python
not x
x and y
x or y
```

**两个要点**：

1. **短路求值**：`and` 左边是"假"就直接停，右边**根本不执行**；`or` 左边是"真"就直接停。

```python
False and 检查经验()   # 右边不执行
True or 检查经验()     # 右边不执行
```

2. **返回的不是 True/False，而是"谁定生死就返回谁"**：
   - `and` 里"假"定生死 → 左边假就返回左边，否则返回右边
   - `or` 里"真"定生死 → 左边真就返回左边，否则返回右边

```python
3 and 5        # 5      （3 为真 → 看右边）
0 or "hello"   # hello  （0 为假 → 看右边）
0 and "never"  # 0      （0 为假 → 短路返回左边）
```

→ 常用它写"默认值兜底"：`name = input() or "匿名用户"`（没输入就是匿名）。

### 4. 赋值运算符

```python
=  +=  -=  *=  /=  //=  %=  **=  &=  |=  ^=  >>=  <<=
```

- `=` 是赋值（注意 `==` 才是等于比较）
- **复合赋值先算右边再赋值**：`a *= b + c` 等价 `a = a * (b + c)`，不是 `a = (a*b) + c`

```python
a = 10
b = 3
a += b        # a = 13
a *= a + 2    # a = 13 * 15 = 195，不是 13*13+2
```

### 5. 位运算符

```python
~ & | ^ << >>
```

- `~x == -(x+1)`（按位取反 = 补码）
- 左移一位 = 乘 2；右移一位 = 整除 2

```python
>>> ~5
-6                  # -(5+1)
>>> 5 << 2
20                  # 5*4
>>> 20 >> 2
5
```

普通业务用不上，性能敏感的底层 / 状态位场景才用。

### 6. 成员 / 身份运算符

```python
in / not in      # 元素是否在容器里
is / is not      # 是不是同一个对象（比较 id）
```

**`==` vs `is`**：判**值**相等 vs 判**对象**相同。

**坑**：Python 对小整数 / 短字符串做了**驻留（intern）**，所以 `a = 'hi'; b = 'hi'; a is b` 可能为 `True`——这是实现细节，**别依赖**。判 `None` 时用 `is`，其余用 `==`：

```python
if x is None: ...        # 正确
if x == None: ...        # 不推荐
```

### 7. 下标与切片

```python
seq[i]              # 单元素
seq[i:j]            # 切片，左闭右开
seq[i:j:k]          # 带步长
```

详见 `turtle-takeaways.md` 5.1 节。

### 8. 一元运算

```python
+x  -x  ~x
```

**坑**：`x ** 2` 优先级高于 `-x`，所以 `-x ** 2` 实际是 `-(x**2)`，要 `(-x) ** 2` 才能正常平方负数。

### 9. 海象 `:=`（Python 3.8+）

在表达式内同时赋值，最常见于循环 / 推导式中避免重复计算：

```python
# 不用 :=
if (n := len(mylist)) > 10:
    print(f"list has {n} elements")

# 推导式里省一次调用
[ y for x in data if (y := f(x)) > 0 ]
```

### 10. 矩阵乘 `@`

NumPy 用得多，普通 Python 极少。

```python
import numpy as np
A = np.array([[1,2],[3,4]])
B = np.array([[5,6],[7,8]])
A @ B       # 矩阵乘
```

## 三、优先级关键规则（务必记住）

1. **算术 > 比较 > 逻辑**：先算加减乘除，再比较，最后才 `and`/`or`。
2. **`**` 高于一元 `+ -`**：`-x ** 2` 是 `-(x**2)`，别写成"平方负数"。
3. **`not` 高于 `and` 高于 `or`**：写复合布尔条件时这个顺序先有概念。
4. **比较可链式**：`a < b < c` 不会被拆成 `(a < b) < c`。
5. **`=` 是语句**，不算真正"表达式"——所以 `x = (y = 5)` 会报错（除非你是指 walrus `:=`）。
6. **`or` / `and` 返回的不是 bool**，而是最后参与判断的那个值；这既是特性也是坑。

## 四、实战建议

- **拿不准就加 `()`**，比记优先级靠谱一万倍。
- 复合布尔条件**每段加括号**：

```python
# 难读
if x > 0 and y < 10 or z == 0 and w > 5:
    ...

# 易读
if (x > 0 and y < 10) or (z == 0 and w > 5):
    ...
```

- 别用 `is` 判字符串/数值内容，只用它判 `None` / 真值常量。
- 业务逻辑里**别用位运算**，除非在处理状态位 / 二进制协议。
- 看到 `a or b or c` 想下"短路"，自然写出**默认兜底**模式：`port = config.get('port') or 8080`。
